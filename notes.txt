Important AI terminology
1. Agent :An agent is a computational entity that perceives information from an environment and performs actions.
2. Environment : The external system or world in which an agent operates.
3. Perception : The process of obtaining information from the environment.
4. State : The representation of the current condition of the environment relevant to decision-making.
5. Action : An operation performed by an agent.
6. Knowledge Representation : The representation of information in a form that a computer can use for reasoning.
7. Reasoning : The process of deriving conclusions from available information.
8. Learning : The process through which a system improves its behavior or predictive capability using data, experience, or feedback.
9. Inference : Using available information and a model to derive an output or conclusion.
10. Model : A mathematical or computational representation of a system, relationship, or learned pattern.
11. Algorithm : A defined computational procedure used to solve a problem or perform a task.
